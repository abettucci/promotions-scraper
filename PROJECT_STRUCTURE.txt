🛠️  TECNOLOGÍAS UTILIZADAS

Anti-detección:
  • Playwright + Playwright-Stealth
  • User-Agent rotation
  • Random delays
  • Geolocation spoofing

Backend:
  • Python 3.8+
  • SQLite (base de datos)
  • AsyncIO (scraping asíncrono)

Frontend:
  • Streamlit (dashboard web)
  • Plotly (gráficos interactivos)
  • Pandas (análisis de datos)

Automatización:
  • Cron (Linux/Mac)
  • Task Scheduler (Windows)
  • GitHub Actions (nube gratis)

---

📈 FLUJO DE EJECUCIÓN

1. scraper.py
   ↓
2. Setup browser (Playwright + Stealth)
   ↓
3. Para cada supermercado:
   • Cargar scraper apropiado (específico o genérico)
   • Navegar al sitio con anti-detección
   • Extraer promociones (selectores CSS dinámicos)
   • Parsear términos y condiciones
   • Guardar en base de datos
   ↓
4. Desactivar promociones viejas
   ↓
5. Generar reporte de estadísticas
